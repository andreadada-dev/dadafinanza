# DadaFinanza branding

- `dadafinanza_logo.svg`: official monochrome vector master supplied by the project owner.
- `dadafinanza_logo_512.png`: official 512×512 PNG supplied by the project owner; used in-app and as the Play Store icon source.
- `dadafinanza_logo_800.png`: 800×800 derivative rendered from the official SVG master.

Android uses the same monochrome mark with a `#212121` adaptive-icon background and a white transparent foreground derived from the official 512×512 PNG.
